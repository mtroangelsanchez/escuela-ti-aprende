# Complemento con AWS Skill Builder

No tengo acceso a tu cuenta de Skill Builder, así que esta lista son recursos **para que los busques y revises tú**. Los nombres exactos pueden cambiar; búscalos por título en <https://skillbuilder.aws>.

## Recursos recomendados (busca por estos títulos)
| Recurso | Para qué |
|---|---|
| **AWS Cloud Practitioner Essentials** | Curso base que cubre los cuatro dominios |
| **Exam Prep Standard Course: AWS Certified Cloud Practitioner (CLF-C02)** | Repaso guiado por dominios con consejos de examen |
| **AWS Certified Cloud Practitioner Official Practice Question Set** | Preguntas oficiales de práctica con explicaciones |
| **AWS Certified Cloud Practitioner Official Practice Exam** | Examen de práctica completo y oficial (puede requerir suscripción) |
| **AWS Cloud Quest: Cloud Practitioner** | Juego de roles con labs prácticos |
| **AWS Builder Labs / Free Tier** | Práctica real con servicios |

## Cómo combinarlo con este repositorio
1. Estudia cada dominio con las guías `01` a `04` y el curso Essentials.
2. Usa el **simulador de este repositorio** como práctica extra cronometrada.
3. Usa el **Official Practice Question Set / Official Practice Exam** de Skill Builder como la medición más fiel al estilo oficial.
4. Anota los errores por dominio y vuelve a la guía correspondiente.

## Recursos oficiales gratuitos
- Guía del examen (CLF-C02): <https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html>
- Whitepapers: *Overview of Amazon Web Services*, *AWS Well-Architected Framework*, *Architecting for the Cloud: AWS Best Practices*.
- Páginas de precios y de planes de Support de AWS.
- Documentación y FAQs de los servicios principales (S3, EC2, IAM, VPC, RDS, Lambda).
