## Cómo Usar Esta Guía

1. **Sigue el cronograma** - Dedica 2-3 horas diarias durante 8 semanas
2. **Lee cada dominio** - Estudia los conceptos y servicios clave
3. **Practica con preguntas** - Cada dominio incluye preguntas al final
4. **Realiza el examen de práctica** - Evalúa tu progreso
5. **Repasa los temas débiles** - Enfócate en las áreas donde fallaste

## Requisitos del Examen

- **Formato**: 65 preguntas (opción múltiple y respuesta múltiple)
- **Duración**: 130 minutos
- **Puntaje mínimo**: 720/1000
- **Costo**: $150 USD
- **Idiomas disponibles**: Inglés, japonés, coreano, chino simplificado, español (Latinoamérica)
